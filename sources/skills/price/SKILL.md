# 가격 계산 점검

## 호출 예시
- `가격`
- `가격 - 현재 파일만`
- `가격 - 수정하지 말고 문제만 알려줘`
- `가격 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- priceCalculation.js와 모든 호출 위치를 먼저 찾는다.
- 기본가, 옵션 추가금, 세트 추가금, 수량의 계산 순서를 확인한다.
- 화면·장바구니·서버의 금액이 일치하는지 확인한다.
- 문자열 숫자, null, undefined, 음수, NaN을 방어한다.
- 중복 계산 로직을 만들지 않고 공통 함수로 유지한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
