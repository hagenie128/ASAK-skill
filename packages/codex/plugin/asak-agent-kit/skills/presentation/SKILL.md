# 발표 준비

## 실행 원칙
- 실제 구현과 확인 가능한 자료만 발표 내용에 포함한다.
- AI가 한 일과 사용자가 직접 이해·수정한 부분을 과장 없이 구분한다.
- 시연 실패 가능성을 고려해 Plan B를 함께 만든다.

## 결과 형식
- 발표 핵심 메시지
- 구현한 기능
- 사용자 흐름과 로직
- 기술 선택 이유
- 문제와 해결 과정
- 내가 직접 설명할 핵심 코드
- 시연 순서
- 예상 질문과 30초 답변
- 시연 실패 시 Plan B
- 마지막 30초 요약
