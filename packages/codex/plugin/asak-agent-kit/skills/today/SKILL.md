# 오늘 작업 정리

## 실행 절차
1. 현재 날짜와 작업 기준 시점을 명시한다.
2. git status, diff, 최근 변경 파일과 관련 문서를 확인한다.
3. 완료, 진행 중, 막힘, 미검증을 근거와 함께 구분한다.
4. 오늘 처리할 우선순위를 최대 3개로 정리한다.
5. 원격 Git 변경은 별도 승인 없이 실행하지 않는다.

## 결과 형식
- 기준 시점
- 오늘 완료한 일
- 진행 중인 일
- 막힌 일과 원인
- 변경 파일
- 검증 결과와 미검증 항목
- 다음 우선순위 3개
- 공부할 코드와 핵심 개념
