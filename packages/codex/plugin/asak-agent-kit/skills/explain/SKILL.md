# 코드 공부용 설명

## 호출 예시
- `설명`
- `설명 - 현재 파일만`
- `설명 - 수정하지 말고 문제만 알려줘`
- `설명 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- 파일 역할을 한 문장으로 먼저 설명한다.
- 입력→처리→출력 흐름으로 나눈다.
- 중요 함수와 상태의 연결을 설명한다.
- 왜 이 방식인지와 오류가 나기 쉬운 부분을 설명한다.
- 마지막에 3줄 요약과 작은 연습문제 1개를 준다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
