# 가격 계산 점검

## 호출 예시
- `가격`
- `현재 파일만 검토해줘`
- `수정하지 말고 문제와 근거만 알려줘`
- `문제를 찾고 안전한 범위에서 수정한 뒤 검증해줘`

## 실행 절차
1. 프로젝트 공통 지침과 사용자 요청 범위를 확인한다.
2. 관련 파일, 호출 위치와 현재 동작을 먼저 찾는다.
3. 아래 점검 기준으로 문제와 근거를 확인한다.
4. 검토 전용 요청이면 파일을 수정하지 않는다.
5. 수정 요청이면 확인된 문제만 최소 범위로 수정한다.
6. 가능한 검증을 실행하고 미검증 항목을 분리해 보고한다.

## 점검 기준
- `priceCalculation.js`를 우선 찾고, 없으면 가격 계산 함수와 모든 호출 위치를 찾는다.
- 기본가, 옵션 추가금, 세트 추가금, 할인, 수량의 계산 순서를 확인한다.
- 화면·장바구니·주문 요청·서버 재계산 금액이 일치하는지 확인한다.
- 문자열 숫자, null, undefined, 음수, NaN과 부동소수점 오차를 방어한다.
- 중복 계산 로직을 만들지 않고 실제 단일 기준을 유지한다.

## 결과 형식
- 결론
- 확인한 범위와 파일
- 발견한 문제와 근거
- 수정한 내용 또는 수정 제안
- 검증 방법과 결과
- 남은 위험과 미검증 항목
- 공부 포인트
