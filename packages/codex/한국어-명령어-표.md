# 한국어 단축 명령어

- **`가격`** → 가격 계산 점검
- **`수량`** → 수량 제한 점검
- **`주문`** → 주문 흐름 점검
- **`리액트`** → React 전체 점검
- **`백엔드`** → Spring Boot/JPA 점검
- **`DB`** → 데이터베이스 점검
- **`API`** → API 연결 점검
- **`피그마`** → Figma 전체 QA
- **`버그`** → 버그 원인 추적
- **`테스트`** → 테스트 및 QA 작성
- **`설명`** → 코드 공부용 설명
- **`배포`** → 배포 전 최종 점검
- **`발표`** → 발표 준비
- **`오늘`** → 오늘 작업 정리
- **`이어서`** → 이전 작업 이어서

## 가장 안전한 사용법

```text
가격 - 수정하지 말고 문제만 알려줘
```

## 수정까지 맡길 때

```text
가격 - 문제를 찾고 안전한 범위에서 수정한 다음 테스트해줘
```

## 범위를 줄일 때

```text
리액트 - 오늘 수정한 파일만
설명 - quantityLimits.js
피그마 - 결제 화면만
```
