# 코드 공부용 설명

## 실행 원칙
- 설명만 요청받았으면 파일을 수정하지 않는다.
- 실제 코드와 호출 흐름을 근거로 설명하고, 없는 동작을 추측하지 않는다.
- 전문 용어는 처음 등장할 때 쉬운 말로 풀어쓴다.

## 결과 형식
1. 한 줄 역할
2. 이 코드가 필요한 이유
3. 입력 → 처리 → 출력 흐름
4. 주요 함수·상태·데이터 연결
5. 실제 호출 순서
6. 오류가 나기 쉬운 부분
7. 왜 이 방식으로 작성했는지
8. 3줄 요약
9. 작은 연습문제 1개
