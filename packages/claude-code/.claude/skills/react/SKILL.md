# React 전체 점검

## 호출 예시
- `리액트`
- `현재 파일만 검토해줘`
- `수정하지 말고 문제와 근거만 알려줘`
- `문제를 찾고 안전한 범위에서 수정한 뒤 검증해줘`

## 실행 절차
1. 프로젝트 공통 지침과 사용자 요청 범위를 확인한다.
2. 관련 파일, 호출 위치와 현재 동작을 먼저 찾는다.
3. 아래 점검 기준으로 문제와 근거를 확인한다.
4. 검토 전용 요청이면 파일을 수정하지 않는다.
5. 수정 요청이면 확인된 문제만 최소 범위로 수정한다.
6. 가능한 검증을 실행하고 미검증 항목을 분리해 보고한다.

## 점검 기준
- useEffect 의존성, 중복 호출, cleanup과 무한 실행 가능성을 확인한다.
- props와 state 중복, 불안정한 key, 파생 상태와 불필요한 렌더링을 확인한다.
- 비동기 요청 경합, 언마운트 후 상태 변경, 로딩·오류 상태를 확인한다.
- UI와 계산·API 로직이 과도하게 결합됐는지 확인한다.
- useMemo/useCallback은 측정 가능한 이득이 있을 때만 적용하고 접근성·키보드 동작도 확인한다.

## 결과 형식
- 결론
- 확인한 범위와 파일
- 발견한 문제와 근거
- 수정한 내용 또는 수정 제안
- 검증 방법과 결과
- 남은 위험과 미검증 항목
- 공부 포인트
