# Figma 전체 QA

## 호출 예시
- `피그마`
- `피그마 - 현재 파일만`
- `피그마 - 수정하지 말고 문제만 알려줘`
- `피그마 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- 프레임·컴포넌트·Variant·Property 이름을 확인한다.
- 색상, 폰트, 간격, Radius, Shadow 토큰을 확인한다.
- Auto Layout, Hug/Fill/Fixed, Constraints를 확인한다.
- CTA, Header, Footer와 콘텐츠 기준선을 화면 간 비교한다.
- 선택·비활성·로딩·오류·품절 상태를 확인한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
