# 이전 작업 이어서

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 현재 브랜치, 변경 파일, 최근 커밋, TODO와 관련 문서를 확인한다.
3. 이전에 완료된 범위와 남은 작업을 근거와 함께 구분한다.
4. 중복 작업을 피하고 가장 우선순위가 높은 미완료 작업부터 수행한다.
5. 원격 Git 변경이나 파괴적 작업은 별도 승인 없이 실행하지 않는다.
6. 가능한 검증 후 다음 단계를 정리한다.

## 결과 형식
- 이전 작업 상태
- 확인한 근거와 변경 파일
- 이미 완료된 범위
- 이번에 수행한 작업
- 검증 결과
- 남은 작업과 다음 우선순위
- 막힌 점 또는 필요한 결정
