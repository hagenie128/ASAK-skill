학원 PC에서 Cursor 설정 복구하기 (개인용)

[방법 A] ASAK-workspace 전체가 있을 때
  1. Cursor 설치
  2. PowerShell:
       cd c:\ASAK-workspace\scripts\my-cursor-kit
       Set-ExecutionPolicy -Scope Process Bypass
       .\install.ps1
  3. Ctrl+Shift+P → Developer: Reload Window

[방법 B] USB zip만 있을 때 (바탕화면 ASAK-my-cursor-kit.zip)
  1. zip 풀기 → 안에 scripts\my-cursor-kit, scripts\powermode 가 있어야 함
  2. 예: c:\ASAK-workspace\ 아래에 scripts 폴더가 오게 복사
  3. 방법 A와 같이 install.ps1 실행

포함 내용
  - extensions.txt     지금 깔린 확장 목록
  - settings.core.json 포맷/테마/태그·괄호 가이드/Power Mode 옵션
  - keybindings.json   Ctrl+Shift+K = 줄 삭제
  - install.ps1        한 번에 설치
  - ../powermode       GIF + setup 스크립트 (install이 자동 호출)

VS Code에도 같이:
  .\install.ps1 -Editor Both
