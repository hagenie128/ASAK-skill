# 개인 학습 메모

Git에 올리지 않는 개인 기록 폴더입니다. Admin·Backend·Kiosk 공부를 여기 한곳에 모읍니다.

## 파일 이름

`YYYY-MM-DD-영역-주제.md`

예: `2026-08-12-매출-화면과-데이터분석.md`

## 기록 템플릿

```md
# 주제

## 문제
- 무엇이 궁금하거나 막혔는가?

## 질문
- 내가 답하고 싶은 구체적인 질문은 무엇인가?

## 확인한 사실
- 실제 파일 / API / DB에서 확인한 사실만 쓴다.
- Mock인지, 실제 연동인지 함께 쓴다.

## 방법
1. 내가 직접 따라 할 순서
2. 확인할 파일 또는 화면
3. 성공 여부를 판단할 기준

## 응용
- 같은 방법을 어디에 더 쓸 수 있는가?
- 데이터를 더 얻으려면 무엇이 필요한가?

## 주의할 점
- 헷갈리기 쉬운 개념, 예외, 아직 미검증인 부분

## 다음에 직접 해 볼 것
- [ ] 작은 확인 항목
```

## 작성 원칙

- "되어 있다"와 "Mock으로만 보인다"를 구분한다.
- 추측보다 파일명, API 경로, DB 테이블명을 짧게 남긴다.
- 비밀번호, 토큰, 실제 개인정보는 쓰지 않는다.
- 한 파일에는 한 주제만 적는다.
