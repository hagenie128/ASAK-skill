# 발표 준비

## 호출 예시
- `발표`
- `발표 - 현재 파일만`
- `발표 - 수정하지 말고 문제만 알려줘`
- `발표 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- 오늘 작업과 구현 기능을 요약한다.
- 기술 선택 이유와 로직 흐름을 초보자도 설명할 수 있게 정리한다.
- 문제와 해결 과정, AI 도움과 직접 수정한 부분을 구분한다.
- 예상 질문과 30초 답변을 작성한다.
- 시연 순서와 실패 시 Plan B를 작성한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
