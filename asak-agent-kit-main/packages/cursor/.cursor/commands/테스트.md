# 테스트 및 QA 작성

## 호출 예시
- `테스트`
- `테스트 - 현재 파일만`
- `테스트 - 수정하지 말고 문제만 알려줘`
- `테스트 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- 정상, 경계, 오류, 회귀 테스트를 작성한다.
- 빈 값, 잘못된 값, 연속 클릭, 새로고침, 뒤로 가기를 포함한다.
- 각 항목에 사전조건, 단계, 기대 결과를 작성한다.
- 자동 테스트와 수동 시각 QA를 구분한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
