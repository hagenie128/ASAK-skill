# 이전 작업 이어서

## 호출 예시
- `이어서`
- `이어서 - 현재 파일만`
- `이어서 - 수정하지 말고 문제만 알려줘`
- `이어서 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- 현재 브랜치, 변경 파일, TODO와 관련 문서를 먼저 확인한다.
- 완료된 작업을 다시 만들지 않는다.
- 남은 작업을 우선순위대로 이어서 수행한다.
- 작업 전후 차이와 다음 단계를 보고한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
