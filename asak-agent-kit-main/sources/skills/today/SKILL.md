# 오늘 작업 정리

## 호출 예시
- `오늘`
- `오늘 - 현재 파일만`
- `오늘 - 수정하지 말고 문제만 알려줘`
- `오늘 - 문제를 찾고 안전한 범위에서 수정해줘`

## 실행 절차
1. 프로젝트 공통 지침을 읽는다.
2. 관련 파일과 호출 흐름을 먼저 찾는다.
3. 아래 기준에 따라 검사한다.
4. 수정 요청이 있으면 최소 범위로 수정한다.
5. 가능한 검증을 실행한다.
6. 쉬운 한국어로 결과를 보고한다.

## 점검 기준
- git diff, 최근 변경 파일과 현재 상태를 확인한다.
- 완료·진행 중·막힌 일·다음 할 일을 구분한다.
- 오늘 우선순위 3개와 검증 항목을 작성한다.
- 학습할 코드와 핵심 개념을 따로 정리한다.

## 결과 형식
- 결론
- 확인한 파일
- 발견한 문제
- 수정한 내용
- 확인한 방법
- 남은 위험
- 공부 포인트
